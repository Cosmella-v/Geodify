# Geodify

This mod converts most menus' backgrounds to the Geode one (SwelvyBG). This includes the following menus:

- CreatorLayer
- GJGarageLayer
- LevelBrowserLayer
- LevelSearchLayer
- LevelSelectLayer
- MODDED LAYERS :D
- and more...

Either create an [issue](https://github.com/Cosmella-v/Geodify/issues) on GitHub for feature requests or bug reports!
Or contact me on discrod with #cosmella_v

> Please note that the mod may only get updates if issues arise or the game updates!
